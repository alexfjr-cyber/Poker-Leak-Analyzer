# Poker-Leak-Analyzer


Como Exportar o seu Relatório



Feche o HM2 para garantir que as alterações e configurações mais recentes sejam salvas no disco.

No seu teclado, pressione as teclas Windows + R para abrir a caixa "Executar".

Digite %appdata% e clique em OK.

Uma pasta do sistema será aberta. Navegue pelos seguintes caminhos:HoldemManager ➡️ Reports

Dentro da pasta Reports, procure pelo arquivo correspondente ao relatório que você deseja enviar. O relatório de posições geralmente se chama Position.xml (ou PositionReport.xml).

Copie esse arquivo e envie para o outro usuário (por e-mail, WhatsApp, Discord, etc.).





Como o outro usuário deve Importar


Fechar o HM2.

Pressionar Windows + R, digitar %appdata% e dar OK.

Navegar até a pasta HoldemManager ➡️ Reports

Colar o arquivo .xml dentro dessa pasta (se o sistema perguntar se deseja substituir o arquivo existente, ele deve clicar em Sim/Substituir).

Pronto! Ao abrir o HM2 e ir na aba Reports ➡️ Position, o layout terá exatamente as mesmas estatísticas e a mesma ordem.




ATENÇÃO!!!


Backup: Recomenda se que faça uma cópia do arquivo Position.xml original antes de substituí-lo, caso queira voltar ao layout antigo depois.


Versão do Software: Certifique-se de que ambos estão usando a mesma build do HM2 (ou versões muito próximas) para evitar conflitos de leitura no arquivo XML.
